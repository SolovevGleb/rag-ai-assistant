# Qdrant Vector Database

В данной папке хранится локальная векторная база данных Qdrant, используемая в RAG-системе.

После создания embeddings текстовые фрагменты документа загружаются в Qdrant, где используются для выполнения semantic search.

В базе хранятся:

- векторные представления документов (embeddings);
- текстовые фрагменты;
- метаданные разделов и тем.

Используется для поиска релевантного контекста перед передачей данных в LLM для генерации ответа.
